# V0.8.0

[English](RELEASE_NOTES_V0.8.0.md) · **繁體中文**

## 逆變器辨識

- 新增 FSP PowerManager Hybrid 5 kW 單相機種校正 Profile。
- 在開機指令或校正寫入前，連續確認三筆 AC 輸入讀值。
- 只有 VR 正常且 VS、VT 同時持續接近 0 時，才詢問使用者是否為 5 kW 單相機。
- 確認單相機後，BUS Target 使用 `VR x 1.414`。
- 完整三相輸入維持使用 `max(VR, VS, VT) x 1.414`。

## 安全保護

- 三筆讀值都顯示只有一相缺失時，在校正前停止。
- AC 相位組合無法安全辨識時停止，不再直接假設為三相機。
- 允許單相機 GS 回應省略 VS／VT 或回傳空欄位，同時維持 VR 與 INGS 的嚴格檢查。
- 校正報告會記錄本次使用的相位 Profile。

## 安裝與版本

- 程式、安裝資訊與文件同步更新至 V0.8.0。
- 維持目前使用者安裝，不需要另外安裝 Python 或 `pyserial`。
- 安裝檔尚未加入程式碼簽章，Windows SmartScreen 可能顯示警告。

## 驗證

- PowerShell 語法與版本比較測試通過。
- 單相、三相、單一缺相與無法辨識輸入的分類測試通過。
- 乾淨的目前使用者安裝 staging 測試通過。
- 5 kW 的 Target 計算、讀值欄位與校正指令，沿用已在多台逆變器完成驗證的
  舊版 5 kW 程式。
- 新增的統一版開機前自動辨識與確認流程，尚未重新接上 5 kW 實機驗證；首次
  現場使用時應先由 Event Log 確認相位判斷結果，再擴大部署。

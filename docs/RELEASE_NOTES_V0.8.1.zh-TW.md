# V0.8.1

[English](RELEASE_NOTES_V0.8.1.md) · **繁體中文**

## 穩定性

- 釋放 X CONTACTS 動畫儀表及 BUS Error Trend 每次重畫時建立的 GDI
  Pen、Brush 與 Font，避免長時間執行後介面失去回應。
- 等待序列埠資料時持續處理 Windows 訊息，通訊逾時期間 Stop 按鈕仍可操作。
- 使用者停止校正時，立即取消正在等待的序列埠讀取。
- 單次序列埠回覆上限設為 4096 bytes，拒絕失控或異常封包。

## 通訊安全

- 電壓欄位只允許正負號及數字。混入文字或格式錯誤的欄位會直接拒絕，
  不再勉強轉換成電壓。
- GS 與 INGS 讀值封包必須具有有效的 `^D` 標頭。
- 校正指令只有在逆變器回覆 `(ACK` 時才視為成功。
- 手動校正失敗時會清空全部待執行指令，避免通訊恢復後執行舊指令。

## 維護性

- 正式程式入口改為 `BUS_Voltage_Correction.ps1`，並使用不含版本號的
  `open_desktop_gui.bat` 啟動。
- 新增免安裝 ZIP 與不顯示命令視窗的 VBS Launcher，可直接放在電腦或
  USB 隨身碟執行，不需要安裝或系統管理員權限。
- 新增可重複執行的邏輯測試，涵蓋封包解析、機種相位判斷、Target 計算、
  校正方向、儀表角度、ACK 回覆及 GitHub 版本比較。

## 驗證

- 正式程式與安裝程式 PowerShell 語法檢查通過。
- 28 項邏輯測試全部通過。
- 安裝檔 staging 與乾淨的單一使用者安裝測試通過。
- 免安裝 ZIP 結構及全新解壓縮啟動測試通過。
- 發布前仍需要連接實機確認通訊與校正流程。
